## Incident Categories & Severity  
### Incident Types  
**1. Cybersecurity Incident**
- Malware infection
- Ransomware attack
- Unauthorized access
- Data exfiltration
- DDoS attack
- Credential compromise  
**2. Data Breach**
- Customer personal data exposed
- Financial data accessed
- System/operational data leaked
- Regulatory data breached  
**3. System Incident**
- System outage/unavailability
- Data corruption
- Performance degradation
- Integration failure
- Backup failure  
**4. Physical Security Incident**
- Facility breach
- Equipment theft
- Fire/environmental damage
- Access control failure  
**5. Fraud/Misconduct**
- Unauthorized transactions
- Employee fraud
- Third-party fraud
